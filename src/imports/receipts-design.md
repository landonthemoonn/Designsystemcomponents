Design a modern minimal AI productivity web app called "Receipts".

The app lets users upload large text message threads and ask questions about the conversation history.

STYLE
Modern glassmorphism UI with subtle blur.
Minimal and elegant like Linear, Notion, and Raycast.
Soft light gray interface with neon yellow accent highlights.

COLOR PALETTE
Background: #F5F5F6
Surface cards: rgba(255,255,255,0.6)
Glass blur effect: backdrop blur 20px
Primary accent: Neon Yellow #E6FF00
Text primary: #111111
Text secondary: #6B6B6B
Divider lines: rgba(0,0,0,0.05)

TYPOGRAPHY
Font: Inter or Helvetica Now
Large titles: bold and airy
Body text: medium weight
Subtext: light gray

LAYOUT
Clean centered dashboard with lots of whitespace.
Rounded corners everywhere (16–24px radius).
Subtle shadows and glass panels.

MAIN SCREENS

1. Upload Screen
Large centered glass card for importing message threads.

Components:
• Drag and drop upload area
• Button: "Import Messages"
• Supported formats list (iMessage, WhatsApp, SMS export)
• Animated progress indicator

Background should be soft gradient gray with subtle noise texture.

2. Chat With Your Messages Screen
Main AI interface.

Layout:
Left sidebar navigation
Main chat area in center
Search bar at top

Sidebar items:
• Threads
• Timeline
• Insights
• Settings

Main chat UI:
Large input field: "Ask your messages anything..."
Example prompts below:
- Who first mentioned moving out?
- When did the argument about keys happen?
- Show all mentions of drugs

Chat responses appear in glass cards with message citations.

3. Timeline View
Visual timeline of events extracted from messages.

Components:
• vertical timeline
• message excerpts
• date markers
• tags like Conflict, Promise, Travel

Accent tags in neon yellow.

4. Insight Dashboard
Analytics view.

Widgets in bento grid layout:
• Most active speaker
• Emotional tone graph
• Message volume by week
• Top topics discussed

Each widget inside rounded glass cards.

INTERACTIONS
Smooth hover states.
Neon yellow highlight on active buttons.
Soft glow on primary actions.

VIBE
Premium, futuristic, calm, intelligent.
Feels like a tool for analyzing important conversations.
Minimal but powerful.
